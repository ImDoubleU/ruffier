# Тест Руфье

Настольное приложение для последовательного проведения функциональной пробы Руфье. Оно выдерживает интервалы теста, проверяет введённые измерения, рассчитывает индекс и показывает возрастную интерпретацию результата.

> Приложение предназначено для учебной и ознакомительной оценки. Оно не ставит диагноз и не заменяет консультацию врача.

## Возможности

- пошаговый сценарий без необходимости самостоятельно засекать время;
- три измерения пульса по 15 секунд;
- таймер для 30 приседаний за 45 секунд;
- обязательный 30-секундный период восстановления;
- расчёт индекса по классической формуле Руфье;
- возрастные пороги для участников от 7 лет;
- вывод пульса в ударах в минуту и понятная расшифровка результата;
- проверка некорректных значений до расчёта.

## Методика

Во время теста фиксируются:

- `P1` — пульс в покое за 15 секунд;
- `P2` — пульс за первые 15 секунд после 30 приседаний;
- `P3` — пульс за последние 15 секунд первой минуты восстановления.

Индекс рассчитывается по формуле:

```text
IR = (4 × (P1 + P2 + P3) − 200) / 10
```

Чем меньше индекс, тем быстрее пульс возвращается к исходному уровню. Интерпретация учитывает возрастную группу участника; после 15 лет применяются единые взрослые пороги.

## Сценарий приложения

1. Пользователь указывает имя и возраст.
2. Приложение проводит замер пульса в покое.
3. Запускается 45-секундный интервал для 30 приседаний.
4. Фиксируется пульс сразу после нагрузки.
5. Выдерживается восстановительный интервал.
6. Выполняется контрольный замер и отображается результат.

## Архитектура

```text
ruffier/
├── main.py                 # точка входа
├── ruffier/
│   ├── app.py              # интерфейс и управление таймерами
│   └── domain.py           # формула, валидация и интерпретация
└── tests/
    └── test_domain.py      # проверки расчётов и границ
```

Расчётная логика не зависит от интерфейса. Благодаря этому формула и возрастные границы проверяются автоматическими тестами, а UI отвечает только за проведение этапов и сбор значений.

## Запуск и проверка

Приложение использует только стандартную библиотеку Python:

```bash
python main.py
```

Проверка расчётной части:

```bash
python -m unittest discover -s tests -v
```

## Ограничения

- результат зависит от точности ручного подсчёта пульса;
- возрастная шкала является ориентировочной;
- тест нельзя выполнять при противопоказаниях к физической нагрузке или плохом самочувствии.
